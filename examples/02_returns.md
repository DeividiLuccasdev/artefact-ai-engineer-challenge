# Return policy with missing facts - acceptance scenario

Status: authored scenario; live transcript pending.

Customer: I regret buying my guitar. Can I return it?

Expected behavior: search the manual; cite page 4. Ask whether this was an online
purchase and when the customer actually received it. Ask about product condition
as needed. Do not use estimated delivery as actual receipt or approve a refund.

Customer: I ordered online and received it three days ago. It is unused in its original box.

Expected behavior: explain the manual's seven-calendar-day online return policy,
the stated return freight and reimbursement process, with the relevant page reference.
Recommend contacting the team to request the return. Do not claim the return was registered.
